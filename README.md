Log Scanner Utility 0.9. Программа для анализа логов с сервера на вредоносную активность. 

    Производится анализ как одного файла лога, так и нескольких в отдельной папке. Принцип основан на анализе данных клиента, который загружает файл на сервер.
    Для проверки, из лога извлекается IP адрес клиента, время загрузки и вычисленный заранее SHA256 хэш файла.
    Проверка на вредоносную активность осуществляется посредством взаимодействия с Virus Total API v3.
    Результаты проверки формируются в виде файла отчета для каждого файла лога. На выбор можно получать отчет в формате CSV или JSON.
    В отчете реализована запись общих счетчиков срабатываний антивирусных систем по следующим категориям:

    - Malicious (Вредоносные)
    - Suspicious (Подозрительные)
    - Undetected (Неопределенные)
    - Harmless (Безвредные)
    
    Также программа ведет свой системный лог о процессе работы.

    Дополнительно реализован минимальный (тестовый) веб-интерфейс ввода данных на языке HTML. Через веб форму осуществляется проверка одного файла лога.
    В ответ браузер получает отчет в json формате.

Запуск

    Нужно клонировать этот репозиторий на локальный компьютер. Далее создать виртуальное окружение и установить модули из файла 'requirements.txt'.
    
    Запуск утилиты производится из виртуального окружения со всеми обязательными именованными аргументами:
        [ python log_scan_cli.py --logfile '...' --apikey '...' --output '...' --format '...' ] 
        
    Где:
        --logfile (файл исходного лога или папка с логами, стандартная 'logs')
        --apikey (VirusTotal Api Key)
        --output (директория отчетов, если стандартная, то 'output')
        --format (тип файла отчета, csv | json)
        
    Справка по утилите: [ python log_scan_cli.py --help ]

    Для локального запуска веб-интерфейса введите: [ python web_api_static.py ], затем в браузере перейдите по ссылке http://127.0.0.1:5000.

    Также есть возможность развернуть веб-интерфейс в контейнере Docker. Для этого выполните следующие действия:
    + docker build -t log_scan_app . (сборка образа)
    + docker run -p 8000:8000 log_scan_app (запустить контейнер)
    + перейти в браузере по ссылке http://127.0.0.1:8000
    + остановить работу контейнера можно командой [ docker stop log_scan_app ] или комбинацией CTRL + C
